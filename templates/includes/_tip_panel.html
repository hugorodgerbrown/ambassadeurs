Hence the "Optional" eyebrow, the outline chips, the disclosure hiding the two low-traffic controls, and the ghost submit — the loudest control on the confirmed page stays "Email ", which is the action that actually matters. Include contract (keep these params explicit at every mount): form — a billing.forms.TipForm instance (bound or unbound) skip_url — where the "No thanks" link goes; the mount decides the target (the standalone page passes accounts:detail). Empty/omitted suppresses the link entirely — the confirmed-match mount (VERB-112) is an inline panel on a page the reader is already on, so it has nowhere to skip to. show_refund_disclaimer — boolean. When true, renders the "refunded if no match is found" copy. Registration-time mounts only; a post-match mount passes false and says nothing about refunds, since by then there is no refund condition left to describe. return_to — optional origin key posted to public:tip_start, which maps it to a return destination (see public.views.tips._RETURN_TO_ROUTES). The confirmed- match mount passes "match" so an abandoned Checkout lands back on the match page rather than on the generic cancelled page. Omitted on the standalone page. The three preset amounts (CHF 5/10/20) are buttons, not form fields — clicking one sets the free-amount number input (the sole "amount_chf" field submitted) and takes the pressed state.
