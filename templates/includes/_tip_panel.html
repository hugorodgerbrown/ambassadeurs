Presented as an aside, not a step (.tip, deliberately not .card): at its real mount it sits below the confirmed-match contact card and the numbered next steps, and must not compete with either. Empty/omitted suppresses the link entirely — the confirmed-match mount (VERB-112) is an inline panel on a page the reader is already on, so it has nowhere to skip to. show_refund_disclaimer — boolean. When true, renders the "refunded if no match is found" copy. Registration-time mounts only. show_no_refund_note — boolean. When true, renders the counterpart copy for a post-match mount: the match is already found, so the contribution is taken straight away and is not refunded. The two flags are alternatives; never set both. return_to — optional origin key posted to public:tip_start, which maps it to a return destination (see public.views.tips._RETURN_TO_ROUTES). The confirmed- match mount passes "match" so an abandoned Checkout lands back on the match page rather than on the generic cancelled page. Omitted on the standalone page. The three preset amounts (CHF 5/10/20) are buttons, not form fields — clicking one sets the free-amount number input (the sole "amount_chf" field submitted) and takes the pressed state.
